# RABBIT HOLE — Decision log

## 2026-10-11 — Confirmed
- Build RABBIT HOLE as a **public-facing product from the start**.
- iOS-first, with an Android-compatible React Native architecture.
- Core loop: Discover → React → Explore → Branch → Discover again.
- Personalized source-grounded discovery, not a conventional AI chat app.
- Low-friction, novelty-rich interaction; avoid empty gamification.
- Codex is the primary coding agent; Expo/React Native preferred; Cursor optional.
- Supabase/PostgreSQL proposed for production backend.
- First milestone is a functioning demo vertical slice, not a full commercial launch.

## 2026-10-11 — Technical proposals awaiting validation
- Starting recommendation factor weights: 30% interests, 25% connections, 20% novelty, 15% quality, 10% diversity.
- 12–20 demo discoveries; eventual 150–300 reviewed seed discoveries.
- Use guest-local state first and integrate persistent multiuser backend afterward.
- Public beta after real iPhone testing and legal/privacy requirements.
